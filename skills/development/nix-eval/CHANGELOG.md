# Changelog

All notable changes to the nix-eval skill will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-02-12

### Added
- Initial release of nix-eval skill
- Support for nix-instantiate and nix eval commands
- Derivation inspection capabilities
- Attribute querying and navigation
- Evaluation debugging guidance
- Comprehensive command examples
- Documentation of nix-instantiate vs nix eval differences

### Features
- Execute evaluation commands with appropriate flags
- Inspect derivation contents and structure
- Query and explore Nix attributes
- Debug evaluation issues with detailed traces
- Support both traditional and flake-based evaluation
- Parse and explain derivation JSON output
