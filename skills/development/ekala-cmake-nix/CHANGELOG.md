# Changelog

All notable changes to the ekala-cmake-nix skill will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-02-12

### Added
- Initial release of ekala-cmake-nix skill
- Comprehensive documentation of Nix attributes that influence CMake builds
- CMake build configuration guidance
- CMake+Nix troubleshooting support
- Build optimization recommendations
- Extensive examples and common patterns
- Best practices for CMake+Nix integration
- Debugging tips and techniques

### Features
- Build CMake-based Nix packages using stdenv.mkDerivation
- Configure CMake builds with appropriate Nix attributes
- Troubleshoot CMake configuration and build failures
- Optimize CMake builds in Nix environment
- Handle multiple outputs and installation paths
- Support both Unix Makefiles and Ninja generators
- Debug CTest integration and test failures
- Explain cmake setup-hook behavior
